Featured Projects

Academic Project

CineMax

Full-Stack Web Application / Database Design Project

CineMax is a cinema ticket-booking web application built around a normalized relational database for managing core cinema operations: movie catalog, screening halls, showtime scheduling, customer registration, seat mapping, and seat-level booking records.

Challenge. Design a structured system for cinema operations and ticket bookings.

Solution. A Flask-based web application supported by a normalized relational database and an Arabic RTL interface.

  • Built the web interface with HTML and CSS, connected to a Flask back end.
  • Created an Arabic right-to-left (RTL) interface, handling RTL layout and text-direction requirements.
  • Designed a relational database schema for movies, halls, showtimes, seats, customers, and bookings.
  • Applied primary keys, foreign keys, and normalized relationships, including Third Normal Form (3NF), for structured, consistent data.
  • Modeled seat-level bookings linking customers, showtimes, and seats, including timestamps and transaction amounts.
  • Designed SQL queries for showtimes, booking history, seat availability, and revenue reporting, with basic data validation.

Team Project

Subnet Calculator System

Web, Networking & Embedded Systems

A subnet-calculator system combining a web interface, a Python Flask backend, TCP socket communication, and embedded hardware. Users enter an IP address and subnet mask through the web interface and receive subnet information calculated locally or through an Arduino TCP server.

Challenge. Connect a web interface to embedded hardware for real-time subnet calculation.

Solution. A Flask backend bridging the web interface and an Arduino TCP server over sockets, with a local calculation fallback.

Architecture. Web interface → Flask backend → Arduino TCP server, and back.

  • Contributed to a complete client-server networking application connecting the web interface, Flask backend, and embedded hardware.
  • Built the web interface for entering an IP address and subnet mask, using JavaScript fetch requests to reach the Flask backend.
  • Implemented Flask API routes for subnet calculation and communication logs.
  • Used TCP socket programming to connect the Flask backend to an Arduino Uno TCP server (Ethernet Shield, port 8080).
  • Exchanged structured JSON responses between the Arduino, Flask backend, and web interface.
  • Calculated the Network ID, Broadcast Address, First/Last Host, and usable host counts, with a local Python fallback when Arduino communication was unavailable.
  • Tested connectivity, TCP connections, and input handling; resolved issues including DHCP failures, static IP configuration, and input-format mismatches.
